# OIBSIP · Data Analytics · Level 1 · Task 3 — Cleaning Data

## Objective
Take a deliberately messy dataset and systematically transform it into a clean,
analysis-ready dataset, documenting every decision.

## Files
- `Cleaning_Data.ipynb`
- `messy_employee_data.csv` — deliberately dirty dataset generated by the notebook (mixed date formats, casing inconsistencies, nulls, duplicates, outliers, wrong dtypes)
- `cleaned_employee_data.csv` — output of the cleaning pipeline (produced when the notebook is run)

## Tech Stack
Python, pandas, numpy, Jupyter Notebook

## What the notebook covers
1. Data quality report (nulls, duplicates, dtype issues)
2. Missing data handling — documented per-column strategy (mode/median imputation)
3. Duplicate removal
4. Standardisation — casing, mixed date formats → datetime
5. Outlier detection (IQR method) — capped/winsorized with reasoning documented
6. Data type correction (IDs as string, dates as datetime, numeric fields as float/int)
7. Before-vs-after summary table
8. Cleaned dataset exported to CSV

## How to run
```
pip install pandas numpy
jupyter notebook Cleaning_Data.ipynb
```

## Note on the dataset
Generated locally to match the spirit of the "messy data cleaning exercise" style
datasets referenced in the task's self-sourcing guideline (e.g. Titanic/Housing-style
dirty data), with intentional nulls, duplicates, mixed formats and outliers injected.
