# OIBSIP · Data Analytics · Level 2 · Task 1 — Predicting House Prices with Linear Regression

## Objective
Build and evaluate a Linear Regression model that predicts house prices from area,
location, room counts and age.

## Files
- `House_Price_Prediction.ipynb`
- `house_prices.csv` — synthetic housing dataset generated by the notebook

## Tech Stack
Python, pandas, scikit-learn, matplotlib, seaborn

## What the notebook covers
1. EDA — null check, descriptive stats, target distribution
2. Feature selection discussion
3. Missing value handling + One-Hot Encoding of Location
4. Correlation heatmap
5. 80/20 train/test split
6. Linear Regression training
7. Evaluation: MSE, RMSE, R²
8. Actual-vs-predicted scatter plot & residual plot
9. Coefficient analysis
10. Bonus: Ridge & Lasso regularised model comparison

## How to run
```
pip install pandas numpy scikit-learn matplotlib seaborn
jupyter notebook House_Price_Prediction.ipynb
```

## Note on the dataset
Generated locally with a known (noisy) price-generating function so the regression has
real, interpretable signal to learn, matching the schema of the Ames Housing / "House
Prices" Kaggle datasets referenced in the task's self-sourcing guideline.
