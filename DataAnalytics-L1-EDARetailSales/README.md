# OIBSIP · Data Analytics · Level 1 · Task 1 — EDA on Retail Sales Data

## Objective
Perform a thorough Exploratory Data Analysis on a retail sales dataset to uncover
patterns, customer behaviour trends, and actionable business insights.

## Files
- `EDA_Retail_Sales.ipynb` — full notebook (generates the dataset, then runs the complete EDA)
- `retail_sales_data.csv` — synthetic transaction-level dataset generated by the notebook (Order Date, Customer Age/Gender, Product Category/Name, Quantity, Unit Price, Sales, Region)

## Tech Stack
Python, pandas, numpy, matplotlib, seaborn, Jupyter Notebook

## What the notebook covers
1. Initial inspection: shape, dtypes, null check
2. Descriptive statistics (mean, median, mode, std) for numerical columns
3. Monthly & quarterly sales trend line charts
4. Customer demographics (age distribution, gender breakdown)
5. Top 10 best-selling products & revenue by category
6. Correlation heatmap
7. Region × Category revenue matrix (non-obvious insight visualisation)
8. Markdown observations after every chart
9. Conclusion with 3+ actionable business recommendations

## How to run
```
pip install pandas numpy matplotlib seaborn
jupyter notebook EDA_Retail_Sales.ipynb
```
Run all cells top to bottom — the dataset is generated by the first code cell, so no
external download is required.

## Note on the dataset
Kaggle access isn't available in the environment this was built in, so a synthetic
dataset was generated with the same schema and realistic statistical properties as the
"Superstore Sales" / "Retail Sales" datasets referenced in the task's self-sourcing
guideline. Swap in a real Kaggle CSV with matching column names and every cell below the
data-generation cell will run unchanged.
