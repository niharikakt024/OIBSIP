# OIBSIP · Data Analytics · Level 2 · Task 2 — Wine Quality Prediction

## Objective
Train and compare Random Forest, SGD and SVC classifiers to predict wine quality from
physicochemical properties.

## Files
- `Wine_Quality_Prediction.ipynb`
- `wine_quality.csv` — synthetic dataset generated by the notebook, matching the UCI Wine Quality schema

## Tech Stack
Python, pandas, numpy, scikit-learn (RandomForestClassifier, SGDClassifier, SVC), seaborn

## What the notebook covers
1. Class distribution inspection
2. EDA — feature distributions & correlation heatmap
3. Class imbalance discussion
4. Feature engineering — binning quality into Low/Medium/High
5. Stratified train/test split + StandardScaler
6. Training 3 classifiers
7. Evaluation — accuracy, classification report, confusion matrices
8. Random Forest feature importance chart
9. Side-by-side model comparison table
10. Conclusion on best model for deployment

## How to run
```
pip install pandas numpy scikit-learn matplotlib seaborn
jupyter notebook Wine_Quality_Prediction.ipynb
```

## Note on the dataset
Generated locally to match the schema and approximate statistical behaviour of the UCI
"Wine Quality" dataset referenced in the task's self-sourcing guideline.
