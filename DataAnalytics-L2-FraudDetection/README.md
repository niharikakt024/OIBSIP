# OIBSIP · Data Analytics · Level 2 · Task 3 — Fraud Detection

## Objective
Build a machine learning pipeline to detect fraudulent financial transactions from a
heavily imbalanced dataset.

## Files
- `Fraud_Detection.ipynb`
- `transactions.csv` — synthetic transaction dataset generated by the notebook (~0.4% fraud rate)

## Tech Stack
Python, pandas, scikit-learn (LogisticRegression, RandomForestClassifier), matplotlib, seaborn

> `imbalanced-learn` (SMOTE) could not be installed in the offline build environment, so
> class imbalance is handled with `class_weight='balanced'` instead — the alternative
> technique explicitly listed in the task's Feature Checklist, and equally production-viable.

## What the notebook covers
1. Class imbalance analysis
2. EDA — transaction amount & time-of-day, fraud vs non-fraud
3. Why accuracy is a misleading metric for imbalanced data
4. class_weight='balanced' imbalance handling
5. Stratified train/test split
6. Training Logistic Regression + Random Forest
7. Evaluation — Precision, Recall, F1, AUC-ROC, confusion matrices, ROC curve
8. Precision/Recall trade-off discussion
9. Feature importance / coefficient analysis
10. Scalability discussion for 1M transactions/hour

## How to run
```
pip install pandas numpy scikit-learn matplotlib seaborn
jupyter notebook Fraud_Detection.ipynb
```

## Note on the dataset
Generated locally to mirror the structure and heavy imbalance of the "Credit Card Fraud
Detection" benchmark dataset referenced in the task's self-sourcing guideline.
