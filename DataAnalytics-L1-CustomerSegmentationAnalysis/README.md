# OIBSIP · Data Analytics · Level 1 · Task 2 — Customer Segmentation Analysis

## Objective
Apply clustering algorithms (K-Means) to segment an e-commerce customer base into
distinct groups based on purchasing behaviour (RFM: Recency, Frequency, Monetary).

## Files
- `Customer_Segmentation_Analysis.ipynb`
- `customer_data.csv` — synthetic per-customer RFM dataset generated by the notebook

## Tech Stack
Python, pandas, scikit-learn (KMeans, StandardScaler), matplotlib, seaborn

## What the notebook covers
1. Load & clean (duplicates, missing Monetary values)
2. Descriptive stats: avg purchase value, frequency, CLV proxy
3. RFM feature selection
4. StandardScaler normalisation
5. Elbow Method to choose optimal K
6. K-Means clustering + scatter plot visualisations
7. Cluster profiling & business labelling (Loyal High-Value / Regular Mid-Value / At-Risk)
8. Customers-per-cluster bar chart
9. Segment-specific marketing recommendations

## How to run
```
pip install pandas numpy scikit-learn matplotlib seaborn
jupyter notebook Customer_Segmentation_Analysis.ipynb
```

## Note on the dataset
Generated locally (no internet access in the build environment) to match the RFM shape
you'd derive from the UCI "Online Retail" dataset referenced in the task's self-sourcing
guideline, with 3 latent customer archetypes baked in so clustering has genuine structure
to discover.
